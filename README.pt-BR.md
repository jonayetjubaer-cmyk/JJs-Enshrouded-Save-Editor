# JJ's Enshrouded Save editor

Editor de saves para Windows desenvolvido pela **Jonaex LTD**. Versão **0.2.0**.

[Baixar no Nexus Mods](https://www.nexusmods.com/enshrouded/mods/249?tab=files) | [Relatar um problema](https://github.com/jonayetjubaer-cmyk/JJs-Enshrouded-Save-Editor/issues/new?template=bug_report.yml) | [Documentação em inglês](README.md)

## Recursos

- Interface compacta com abas para personagem, inventário, equipamento, habilidades, conhecimento e servidor.
- Tabelas com pesquisa e ordenação; edição de níveis, quantidades, melhorias e gemas.
- Desfazer, descartar alterações, backups automáticos e restauração.
- Traduções completas da interface em italiano, francês e alemão. Inglês e a opção original em português também estão disponíveis.
- Seleção de idioma na tela inicial, antes de abrir um save, com a escolha memorizada.
- Temas claro, escuro e do sistema.

## Uso e suporte

Baixe e extraia o ZIP para Windows x64 do Nexus Mods. Mantenha a licença e os créditos junto do executável. Feche o jogo antes de salvar e conserve uma cópia independente do save original.

Para investigar um problema, envie o .ksd afetado e o backup anterior à edição em um ZIP, em pastas separadas. Anexos em issues públicas são públicos; para combinar um envio privado, contate RurushEdward no Nexus antes de enviar arquivos. Consulte [SUPPORT.md](SUPPORT.md).

Esta é uma versão de prévia. Consulte [TESTING.md](TESTING.md) para os testes e limitações. Os requisitos de compilação são Windows, Node.js 24, Rust MSVC e Microsoft C++ Build Tools; as instruções completas estão no [README em inglês](README.md).
