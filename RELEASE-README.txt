JJ's Enshrouded Save editor 0.2.2
Author and publisher: Jonaex LTD
Nexus: https://www.nexusmods.com/enshrouded/mods/249
Jonaex LTD Discord: https://discord.gg/w5qGfqm7UY

Extract this ZIP and run JJs-Enshrouded-Save-Editor.exe on Windows x64.
This is a standalone application; install manually, not through Vortex.
Microsoft Edge WebView2 Runtime is required.

Language can be changed immediately on the opening screen, before opening a save:
Language / Lingua / Langue / Sprache -> English, Portugues, Italiano, Francais, Deutsch.
The choice applies immediately and is remembered next time. On first launch,
the editor detects the system language and otherwise uses English.
Italian, French and German cover the interface, dialogs, validation messages,
item names, skills/descriptions and stat labels. Internal game identifiers,
player names, paths and the original legal license text remain unchanged.

Close Enshrouded and keep an independent backup before editing a .ksd file.
Select a character or use Open, make changes, then Save.
Changes remain in memory until saved. Undo is available before saving.
An automatic backup is made before each save under:
Documents/Enshrouded-Backups/jj-editor

Open Item catalog to browse without a save. In Inventory > Add item…,
check several items, set their quantities, and add them in one Undo step.
Hover over icons for a larger preview or select a row to inspect stats.
In Skills, switch to Skill tree to pan, zoom and select nodes to edit ranks.
The skill-point budget validates edits; it does not grant points in the game.

This is a preview release. Automated tests and sample-data UI checks passed;
loading an edited real character in the game has not yet been validated.
Optional SFTP server password storage remains unencrypted.
